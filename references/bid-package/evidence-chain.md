# 投标证明材料证据链复核

证明材料的核心不是“附件里有一张图”，而是证明主体、对象、范围、期限和招标要求全部闭合。

## 一、统一七字段

每份关键证明至少记录：

1. **出具主体**：制造商、认证机构、检测机构、投标人或电商平台；
2. **被证明对象**：产品、型号、系统、人员、项目或合同；
3. **受益/授权主体**：是否明确指向本投标人和本项目；
4. **数量与范围**：是否覆盖全部投标数量、配件、软件和服务；
5. **期限**：签发日、有效期、质保起点、服务终点；
6. **生效条件**：购买、付款、登记、激活、验收、金额区间、使用环境；
7. **核验方式**：证书号、查询页、二维码、盖章函、订单或发票。

任一关键字段不闭合，都应明确写出“缺什么”，不能用“材料已提供”掩盖。

## 二、原厂质保

证据强度从高到低：

1. 制造商针对本项目、型号、数量直接盖章承诺；
2. 制造商通用政策+明确型号范围+可核验条款；
3. 已购买且已登记/激活的官方延保订单或凭证；
4. 投标人承诺中标后购买官方延保；
5. 官方商城商品页截图；
6. 投标人自行承担的售后承诺。

审查时必须区分：

- “原厂质保10年”与“原厂6年+投标人负责后4年”不是同一事实；
- “中标后购买”不是当前已经购买或激活；
- 商品页写“未激活不生效”时，必须找登记/激活路径和责任人；
- 商品页存在购机金额、型号、家用/商用环境等适用条件时，要与投标型号、单价和使用场景比对；投标单价不必然等于制造商购机价格，因此只能写“表面不一致，需原厂确认”，不能直接断言不能购买；
- 原厂空调质保不能自动扩展为控制器、软件、物联网卡、支架等“所有产品原厂质保”；
- 招标只要求最低3年而评分给10年时，原厂6年可能已满足实质要求，但10年加分档仍可能不认。必须把“废标风险”和“评分风险”分开。

## 三、本国产品声明

- 产品有型号时，声明中的产品名称应带型号；不能只写功能名称。
- 生产厂名、厂址应能与生产厂营业执照或权威信息对应。
- “品牌方”“销售商”“运营服务商”“投标人”不当然等于生产厂。
- 物联网卡、软件、安装服务等先判断是否属于政策所称货物，再决定是否声明。
- 若优惠门槛按本国产品成本占全部产品成本的比例计算，先用报价数据核算达到门槛所需的最小真实声明范围。不要为了显得完整，把无法证明的低金额产品也纳入声明。
- 声明遗漏通常先影响价格优惠；声明内容不实可能升级为虚假材料风险。必须回查招标文件对声明真实性的判决条款。

## 四、中小企业声明

- 货物项目看制造商企业规模，不是只看投标人规模；服务项目看承接主体，按招标行业口径执行。
- 标的名称和所属行业应逐项与招标文件对应，不得把“附件/安装/平台”等自行合并后遗漏。
- 从业人数、营业收入、资产总额应为规定年度口径；企业类型按行业划型标准判断。
- 非专门面向中小企业项目，声明缺失或无效通常影响价格扣除；专门面向中小企业项目则可能是资格风险。先判断项目属性，再分级。

## 五、强制节能、环保和认证

- 强制节能产品证书：证书号、品牌、整机型号、认证机构和投标截止日有效期必须匹配；型号在附件清单时要定位具体页。
- 环境标志：区分实质要求、前附表一般要求和评分材料；证书本体与型号附件要同时核。
- 3C/检测：招标要求整体产品时，不能只交电源模块证书；型号有前缀差异时需要制造商盖章的一致性说明。
- 校准证书：核对被校准设备型号、委托单位、CNAS标识、校准日期和建议下次校准日期；网页“1.0级含义”不能替代校准证书。
- 体系认证：证书、有效期、认证范围和官方查询截图成套核查；查询页仅有企业名而无证书状态时不闭合。

## 六、页码与检索

证明材料实际存在但目录/清单页码错误时，单列“检索风险”。同时记录：PDF物理页、文档印刷页、目录填写页。不得因目录页码错误误写“未提供证书”，也不得因证书存在就忽略定位错误。
